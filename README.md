# UTS - Pendaftaran Seminar Teknologi

## Tahapan Pengerjaan
1. Menambah menu Seminar di navigasi
2. Menambah section#seminar setelah section#contact
3. Membuat form dengan 5 input: nama_peserta, nim, prodi, pilihan_seminar, alasan
4. Membuat validasi JavaScript validasiSeminar()
5. Membuat proses PHP POST, htmlspecialchars, session, PRG

- Isi form seminar lengkap -> data tampil di atas form
- Kosongkan salah satu field -> muncul alert "Semua field wajib diisi!"
- Refresh setelah kirim -> tidak resubmit
- Form Kontak tetap berfungsi normal
